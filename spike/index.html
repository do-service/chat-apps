Уведомления

Одинаковый chat группируется/заменяется, одинаковый event ID дедуплицируется. Для проверки account switch измените ID и нажмите «Установить account». Звонок истечёт через 20 с; поздний клик не должен активировать чат. Таймер renderer может задержаться в фоне — получение реальных событий здесь не проверяется.
